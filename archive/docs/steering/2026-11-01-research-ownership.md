**Where the instructions steered us.** Both root files made baseline profiles, floors, run receipts and losing experiments mandatory. Those rules disciplined experiments after target selection. The November 1 retrospective's name-free query found keell0renz at result 17. That demonstrates recoverability that day. It does not establish when the repo became discoverable. **What the next session must do differently.** The identical new root section requires an independent search, a first-principles alternative, a comparison in whole-score units, and a handoff of unresolved wins. These steps belong to the experiment chooser. Merely adding papers or competitors to a list earns no credit. For MoE, a consumer-dependency sketch would ask whether each token needs every expert to finish. A byte inventory would distinguish compression of the scale stream from compression of dense weights. Either question can be posed before an external implementation supplies an answer. An implementation still needs ordering, precision and measured performance evidence.

It cannot validate independent discovery. After the resulting experiment, compare its measured whole score with the forecast.
