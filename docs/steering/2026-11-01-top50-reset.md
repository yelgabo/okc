## Approved fork and empirical target

The user authorized using an attributed layer fork after an ordering, precision and license audit. This supersedes measurement-only policy for that layer base. The exact external layer passed 13 official tests at 2.248791× (95% CI 2.215059–2.282522) on our H200 check 3a5f879df0d44825. Its point estimate is 1.35% below the observed rank-50 threshold in required additional score. Its medians were lower on all twelve shapes than the owned best-entry receipt. The two runs used different inputs and machines may differ. [Per-shape comparison](evidence/2026-11-01-top50/layer-external-shapes.md).

A passing reference build is valuable as a performance target but does not establish adoption eligibility. The fork generator pins upstream by normalized SHA, retains its notices and embeds LICENSE/NOTICE in the single-file output. The initial glue patch disables deferred two-row normalization on T1, which read the producer's partials ahead of a dependency wait and moved the BF16 activation boundary. It selects the existing path with explicit intermediate activation instead. Pooler FP32 split sums are rounded to BF16 before pre-expert RMS. Generic fallback residual paths likewise restore BF16 projection and normalized-branch rounding. The short final boundary now waits before carry/tail reads. The diagnostic preparation A/B which inspected captured outputs before graph replay is disabled. Remaining active-path audits include attention quantization and scratch lifetime, expert gate/up and down-projection rounding, inter-CTA completion/publication and actual projection code generation. No public submission of the upstream file is warranted on the current evidence.
