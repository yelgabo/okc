2. **Split fixups and terminal drain.** A split unit has exactly one first-stage owner, hence one slot; one CTA can start at most one split unit at its trailing boundary. Acyclic B event witness includes next-segment begin, previous pending publication, segment completion and other-share dependencies; all modeled nodes topologically drain.
