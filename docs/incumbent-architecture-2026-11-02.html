Inside the retained expert kernel

At 128 and 256 tokens, the selector uses MAIN WGS. At 32 tokens it uses B4. Both paths separate packed-weight loading from activation loading, while the compute warpgroups decode the weights into registers.

5–8Tiny2

The November 2 proposal moves weight decoding into a separate producer and feeds shared BF16 operands to WGMMA. It is still in implementation. The incumbent shown here uses register operands and K256 stages.
