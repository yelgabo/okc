## Edge proof: glue boundary b1 with `launch_dependents` at entry

Line numbers are in the judged file. `GMB_TRIG = 'entry'` (line 18212) makes `_gmb_trig` move the boundary's
`griddepcontrol.launch_dependents` to kernel entry, before its mid-kernel `griddepcontrol.wait`. The kernel after the
boundary (K3) may then launch while the kernel before it (K1, the o projection) is still running, so K3 must not read
anything K1 or the boundary writes before K3's own wait.

- `PDL = False` (line 104), so the GLE `_after_attention` path is dead. BFQ runs only at T = 128, outside
  `PDL8_T = (1, 8, 16, 32)` (line 18184), and at T = 32 the boundary is the Gluon `_graft_row_boundary_pre_cg`.
- At T = 1 and 8, SL b1 (`_pdl8_b1`, line 18458, edge "b1") is followed by `gle_pr` (line 19112), which is `sk2_kernel`
  with FUSE on. Before its wait (line 8244) it touches only the weight stream, `ptab` (built in prepare), the
  `__grid_constant__` tensor map, mbarrier inits and shared memory. The x loads, the FP32 router stages that read the
  boundary's `hr` and the `fused_part` / `rcnt` writes (line 8502) come after the wait. With interleaving on, the router
  stage sits at slot `OFF >= P` (line 16812), so every pre-wait stage is a weight stage. Its triggers (lines 8271, 8437)
  follow the wait, so the route kernel after it cannot launch before the boundary completes, and the boundary cannot
  complete before its own wait has seen K1 complete.
- When `ppick` is not bfp, the next kernels are `F.linear` and `router_fp32_kernel`, launched with `<<<>>>` and no PDL
  attribute (line 16566).
- Graft b1 (line 18983) at T = 16 is followed by `bfp_fused_pooler_router` or `_bfp_gemm`, the same sk2 kernel and wait
  order. The `dense(h, pr)` path at T = 16 is inferred safe; not every kernel `dense` can pick was traced.
- WAR: before its wait, K3 writes only shared memory.

The constraint this leaves: every PDL kernel that can follow b1 must keep its `h` / `hr` / x32 reads and its global
writes after its `griddepcontrol.wait`. The `!FUSE` cp.async prologue described at line 16641 issues loads before the
wait, so it must stay off for the fused pooler. Graft b1 enables glue PDL whenever `_PDL8` is set, without checking the
"b1" edge (lines 18964-18969); SL b1 checks it. That predates `GMB_TRIG`.
