T32: old skinny → current B4 / WGS.

Source comparison · default T32

T32 changes from 8 compute warps plus one producer to four compute warpgroups plus two producers. Both compute the same two expert phases and weighted expert output.

At T128 and T256, compare scheduling and scale bytes.

Work ownership changes

Older mode 47 owns whole A units and claims B units dynamically. Current WGS assigns cost-weighted stage ranges to both phases and uses fixup storage for split units.

Eligible scales use six bits

The four-bit weight codes stay exact. Scale packing activates only after its range check; byte-scale and non-PRMT fallback dispatch remain available.

The release wrapper is simpler

One prepared control state replaces the private experiment wrapper. No observer or private timing harness runs in this release. That cleanup is not evidence of a scored kernel speedup.

Large-load source comparison · principal flow

Both larger-load engines retain four compute warpgroups and two producers. Shared rings, the BF16 intermediate, mathematical boundaries and the required publication ordering remain part of the implementation.
