# Ruled out

Every experiment that lost or was closed, with the evidence and what it rules out. Check here
before proposing an experiment; reopen an entry only with new evidence that changes its
measured ceiling, and say what that evidence is. Full details are in the runs logs named per
entry.

Each row rules out the mechanism as built, in the design it was tested inside, on the judge's
workload. It does not reject the underlying idea. An idea that lost as a single ingredient in
the old design can come back as part of a structurally different design.

Architecture-level losses (a whole design family against the incumbent, e.g. the staged
two-launch MoE) are parked, not pruned. The comparison was against the components of that day,
and component work keeps moving the baseline both designs share. Each such row names its
revisit trigger: the component changes that would shift the outcome (e.g. for the staged MoE,
cheaper phase B or setup, which shrinks the overlap the fused kernel wins on). When a trigger
lands, re-measure the parked design against the new incumbent with its own up-to-date
components, in the same process, before calling it lost again.
